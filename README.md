# 🎵 Информационная система анализа музыкальных предпочтений

Курсовой проект по дисциплине «Базы данных». Десктопное приложение для автоматизации проведения опросов, анализа музыкальных предпочтений по демографическим категориям и формирования пластинок на основе реальных данных.

## 🛠 Стек технологий
- **Язык:** C# (.NET)
- **UI:** Windows Forms
- **СУБД:** MySQL 8
- **Доступ к данным:** ADO.NET
- **Инструменты:** Visual Studio, MySQL Workbench

## ✨ Ключевые особенности реализации

### 🗄 База данных
- Спроектирована с нуля: **10+ таблиц**, нормализация до **3НФ**, концептуальная модель в нотации Питера Чена.
- **5 триггеров** для автоматизации и целостности:
  - `trg_calculate_preference_weight`: авторасчет веса голоса (`weight = 6 − rank`).
  - `trg_validate_survey_preferences`: валидация уникальности рангов (1–5) и количества песен.
  - `trg_update_age_category`: автообновление возрастной группы при изменении возраста.
  - `trg_update_song_statistics`: пересчет популярности песни.
  - `trg_log_survey_deletion`: аудит удалений опросов.
- **7 хранимых процедур**, включая `sp_create_record_from_top_songs` для автоформирования пластинок по топ-N.
- **5 представлений (Views)** для аналитики (рейтинги, демография, сводная статистика).
- **8+ индексов** (поисковые, составные, по внешним ключам) для оптимизации запросов.

### 💻 Клиентское приложение
Модульная архитектура из 8 форм:
1. `ConnectionForm` — подключение к БД.
2. `MainForm` — главная навигация.
3. `SongsForm` / `PerformersForm` — управление каталогом.
4. `ParticipantsForm` / `SurveyForm` — регистрация участников и опросов.
5. `AnalyticsForm` — отчеты по полу и возрасту.
6. `RecordsForm` — формирование и история пластинок.

## 🚀 Как запустить
1. Установите **MySQL Server** и импортируйте SQL-скрипты из папки `database/` (создание таблиц, триггеров, процедур).
2. Откройте решение `.sln` в Visual Studio.
3. В форме подключения укажите параметры вашей локальной БД.
4. Запустите проект (F5).

## 📊 Тестирование
Система успешно протестирована на наборе данных: 15 участников, 25 песен, 5 сформированных пластинок. Все триггеры и хранимые процедуры отрабатывают корректно.
