# 🎵 Информационная система анализа музыкальных предпочтений

Курсовой проект по дисциплине «Базы данных». Десктопное приложение для проведения опросов о музыкальных вкусах, аналитики по демографическим группам и автоматического формирования пластинок.

## 🛠 Стек технологий

- **Язык:** C# (.NET Framework)
- **UI:** Windows Forms
- **СУБД:** MySQL 8
- **Доступ к БД:** ADO.NET (MySql.Data)
- **Инструменты:** Visual Studio, MySQL Workbench

## ✨ Функционал

### База данных
- 10+ таблиц, нормализация до **3НФ**
- Концептуальная модель в нотации Питера Чена
- **5 триггеров:**
  - `trg_calculate_preference_weight` — автоматический расчёт веса голоса (`weight = 6 − rank`)
  - `trg_validate_survey_preferences` — валидация количества песен и уникальности рангов
  - `trg_update_age_category` — автообновление возрастной категории
  - `trg_update_song_statistics` — пересчёт статистики популярности
  - `trg_log_survey_deletion` — аудит удалений опросов
- **7 хранимых процедур**, включая `sp_create_record_from_top_songs` — автоформирование пластинок по топ-N
- **5 представлений (Views)** для аналитики
- **8+ индексов** для оптимизации запросов

### Клиентское приложение (8 форм)
1. `ConnectionForm` — подключение к БД
2. `MainForm` — главное меню
3. `SongsForm` — каталог песен
4. `PerformersForm` — справочник исполнителей
5. `ParticipantsForm` — участники опросов
6. `SurveyForm` — регистрация результатов опросов
7. `AnalyticsForm` — отчёты по демографическим группам
8. `RecordsForm` — формирование пластинок

## 🚀 Как запустить

1. Установи **MySQL Server 8** и **Visual Studio 2022**.
2. Выполни SQL-скрипт из папки `database/` для создания БД.
3. Открой решение `MusicPreferences.sln` в Visual Studio.
4. В `ConnectionForm` укажи параметры подключения к БД.
5. Запусти проект (F5).
